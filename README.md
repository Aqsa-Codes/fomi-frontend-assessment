# Fomi — AI Image & Video Generation Platform

A responsive AI-powered creative workspace built as part of the Fomi Frontend Technical Assessment.

## Live Demo

[View Fomi Live](https://fomi-frontend-assessment-dn3c.vercel.app/)

## Features

- Image generation with multiple output options.
- Video generation with mock API responses.
- Custom text prompts.
- Aspect ratio selection.
- Image and video mode switching.
- Generation loading and error states.
- Creation gallery with responsive layouts.
- Interactive controls and hover effects.
- Responsive design for desktop, tablet, and mobile.

## Tech Stack

- Next.js
- JavaScript
- React
- Tailwind CSS
- Next.js API Routes
- Git and GitHub
- Vercel

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Aqsa-Codes/fomi-frontend-assessment.git
```

Navigate into the project:

```bash
cd fomi-frontend-assessment
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in browser.

## API Routes

- `/api/generate` — Mock image generation endpoint.
- `/api/generate-video` — Mock video generation endpoint.

**Note:** This assessment uses mocked API responses and sample media. It does not connect to a real AI generation service.
